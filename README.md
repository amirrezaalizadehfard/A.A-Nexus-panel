## 🇬🇧 English

### 📖 About the Project

This project is a modern configuration management and creation panel that allows you to generate and use **VLESS**, **Trojan**, and **Shadowsocks** configurations completely for free, without needing a Virtual Private Server (VPS). It enables you to create dedicated configurations for individual users while efficiently managing traffic limits, expiration dates, and user counts.

#### ✨ Key Features
* **Multi-Protocol Support:** Generate configs for `VLESS`, `Trojan`, and `Shadowsocks`.
* **User Management:** Create separate configurations for each user.
* **Resource Control:** Easily manage data limits (traffic), expiration times, and active user counts.
* **Zero Cost:** Designed to run smoothly on Katabump's free tier without needing a VPS.

### 🚀 Installation & Deployment Guide on Katabump

Follow these steps carefully to deploy your panel for free:

1. **Prepare the Files:**
   Download the project files from this repository and extract the ZIP archive on your device.

2. **Generate a Temporary Email:**
   Go to [TempMail](https://www.tempmail.lol) and generate a temporary email address.

3. **Register an Account:**
   Visit [Katabump](https://www.katabump.com) and sign up for a new account using the temporary email you just created.

4. **Create a Server:**
   * Log into your dashboard and navigate to the **Order** section to create a new server.
   * Configure the server settings strictly as follows:
     * **Name:** Choose any desired name for your server.
     * **Type:** Set to `Node.js`.
     * **Resources:** Set to `0 credits`.
   * Click the create/order button to finalize the server setup.

5. **Upload Project Files:**
   * Wait a few minutes, then go to your dashboard and open the servers list to view your newly created server.
   * Click the **See** button located in the **Action** column next to your server details.
   * On the opened page, under the **Access Server** section, click the **Go to Server** button.
   * From the left-side menu of the new window, navigate to the **Files** section and upload the `index` and `package` files from your extracted project folder.
   * In the left sidebar (just below the server name), you will see three power control buttons (**Start**, **Stop**, and **Reboot**). Click the **Reboot** button and wait a few minutes until the status indicator next to the server name turns **green**.

6. **Access the Admin Panel:**
   * Navigate to the **Console** tab from the left menu to find your admin panel link.
   * Copy the generated link and paste it into your web browser.
   * Log in using the default credentials:
     * **Username:** `admin`
     * **Password:** `admin`
